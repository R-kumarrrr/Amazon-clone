# 🛒 Amazon Clone (HTML & CSS)
A simple, responsive clone of the Amazon India homepage built using only HTML and CSS. This project was created to practice frontend development skills by replicating a real-world e-commerce UI layout.

## 📌 Features
🖥️ Fully structured homepage layout inspired by Amazon.in

📦 Product cards with hover effects

📱 Responsive design for desktop and mobile views

🔍 Search bar, navigation bar, and footer sections

🎨 Pure HTML and CSS (no JavaScript or frameworks used)

## 💻 Technologies Used
HTML5

CSS3

Flexbox & Grid for layout

Media queries for responsiveness
